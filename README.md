# Toho-Project-Second-games_-Picture-RPG_Powerd-by-zuyasi.github.io

このリポジトリには、東方Project二次創作の Scratch 作品
「幻想航空鉄道運転シュミレーター」と、その関連素材が含まれています。

## 収録内容

| パス | 内容 |
| --- | --- |
| `幻想航空鉄道運転シュミレーター.sb3` | Scratch 3 形式のゲーム本体 |
| `幻想航空鉄道シュミレーター/キャラクター/` | キャラクター画像素材 |
| `幻想航空鉄道シュミレーター/背景/` | 背景画像素材 |
| `幻想航空鉄道シュミレーター/ボタン/` | UI用ボタン画像素材 |
| `幻想航空鉄道シュミレーター/音楽/` | ゲームで利用する音楽素材 |
| `credit.html` | クレジットページ |

## 遊び方

`幻想航空鉄道運転シュミレーター.sb3` を Scratch 3 または TurboWarp に読み込んでプレイしてください。
